## 코드 읽기

**Q9.** 아래 코드에서 `data` 가 파괴 타입 + Mineral 이고 `damage = 2`, `targetMask` 가 Flower 와 Tree 만 포함할 때 반환값은? Mineral 만 포함하면?
```csharp
case WorldObjectHitKind.PotionDamage:
    if (data.worldObjectDropType != WorldObjectDropType.Destroying || damage <= 0)
        return 0;
    return (targetMask & (1 << (int)data.worldObjectType)) != 0 ? damage : 0;
```
(힌트: enum 은 None=0, Flower=1, Tree=2, Mushroom=3, Grass=4, Mineral=5, Bone=6)

**Q10.** 아래 `Apply` 일부에서 사본 버전이 7 이고, 적용 메시지가 Version 7 이면 어떤 상태를 반환하나? Version 9 이면? Version 8 인데 `Previous` 가 사본의 남은 횟수와 다르면?
```csharp
if (apply.Version <= _version) return WorldObjectApplyStatus.Ignored;
if (apply.Version != _version + 1) return WorldObjectApplyStatus.VersionGap;
if (!_entries.TryGetValue(apply.NetworkId, out Entry entry)
    || entry.Remaining != apply.Previous
    || apply.Remaining < 0
    || apply.Remaining >= apply.Previous)
    return WorldObjectApplyStatus.Inconsistent;
```
