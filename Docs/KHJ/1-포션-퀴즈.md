## 객관식
**Q1.** 함정 포션에 대한 설명으로 옳은 것은?
1) 함정 포션은 별도의 `PotionData` SO로 미리 만들어 둔다.
2) 폭발 범위는 함정 키워드를 따른다.
3) 원본 포션에 키워드 하나가 붙고, 효과는 원본과 키워드가 모두 적용된다.
4) 정신력이 낮으면 항상 함정 포션이 된다.

**Q2.** `Random.Range(0, 100) < chance` 판정에서 `chance`가 0과 100일 때 결과는?
1) 0 = 항상 성공, 100 = 항상 실패
2) 0 = 항상 실패, 100 = 항상 성공
3) 둘 다 50%
4) 0 = 항상 성공, 100 = 99% 실패

**Q3.** 몬스터 한 마리가 콜라이더 3개를 가지고 폭발 범위 안에 있다. 효과는 몇 번 적용되는가?
1) 3번 2) 1번 3) 0번 4) 레이어에 따라 다름(항상 3번 이하 무작위)

**Q4.** `GaugeChangePotionEffect`(수분 +10)가 적용되는 대상은?
1) 범위 안 모든 플레이어 2) 범위 안 모든 `IDamageable` 3) 내 플레이어(`IsLocalPlayer`)만 4) 월드 오브젝트만
